# Fixed replies, used when the model is not consulted or its output is rejected.
#
# A missed call with no chat history gives the model nothing to personalise
# from, so it is skipped entirely - which used to mean the same sentence went
# out every single time. Anyone who called twice could tell. These say the same
# thing thirty ways instead, picked at random, never the same one twice in a row.
#
# One per line. Blank lines and #comments ignored. Do not sign them: SIGNOFF is
# appended separately, so a name here would appear twice.
#
# [casual] is used for everyone; [formal] replaces it for contacts whose saved
# name carries an honorific (Bhai, Sir, Dada, Didi, Apu...), matching what the
# model is told to do for those same contacts.
